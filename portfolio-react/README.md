# Jaswant Singh - Portfolio (React Version)

An interactive developer portfolio built with React, featuring two distinct experience modes: UI Mode and Terminal Mode.

## 🚀 Features

### Mode Selection
- **UI Mode**: Beautiful visual portfolio with GitHub dark theme, smooth animations, and interactive elements
- **Terminal Mode**: Full terminal experience with git commands, autocomplete, and command history
- Seamless mode switching at any time

### UI Mode Features
- 🎨 GitHub-inspired dark theme with terminal aesthetics
- ✨ Matrix rain background effect with animated grid and gradient orbs
- 📱 Fully responsive design
- 🎯 Smooth scroll animations
- 💻 Terminal-style navigation and command prompts
- 📊 Project showcases with impact metrics
- 🔗 Social links and contact information

### Terminal Mode Features
- 💻 Full terminal interface with 20+ interactive commands
- ⚡ Git command support (git log, git status, git branch, git remote, etc.)
- 🔍 TAB autocomplete with smart suggestions
- 📝 Command history navigation (↑↓ arrows)
- 🎨 Syntax-highlighted output
- 🎯 Quick command buttons for easy access
- 🥚 Easter eggs!

## 🛠️ Tech Stack

- **React 18** - UI library
- **Vite** - Build tool and dev server
- **CSS3** - Styling with CSS custom properties
- **Font Awesome** - Icons
- **HTML5 Canvas** - Matrix rain animation

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎮 Terminal Commands

Try these commands in Terminal Mode:

### Git Commands
- `git log` - View work history with project commits
- `git status` - Check current status and availability
- `git branch` - List all skill branches
- `git remote` - Show social media links
- `git config --list` - View personal configuration
- `git diff` - See before/after impact metrics
- `git show --stat` - Display detailed career statistics

### Info Commands
- `whoami` - Display developer profile
- `pwd` - Show current role/path
- `ls` - List projects
- `skills` - Display technical skills
- `achievements` - Show key achievements
- `contact` - Show contact information

### Utility Commands
- `help` - Show all available commands
- `clear` - Clear terminal output
- `echo $ROLE` - Print role variable
- `echo $EXPERTISE` - Print expertise variable

### Easter Eggs
- `sudo make me a sandwich` - 🍞

## 🎨 Mode Switching

You can switch between modes at any time:
- In UI Mode: Click the "Switch to Terminal Mode" button (bottom right)
- In Terminal Mode: Click the "Switch to UI Mode" button (top right)
